## 3. Full Description (Max 4,000 characters)

```markdown
Guanaco is a fast, elegant, and 100% private mobile task manager designed specifically for Vikunja (the open-source, self-hosted to-do platform).

Built from the ground up for speed and privacy, Guanaco gives you full control over your productivity without third-party tracking, analytics, or cloud lock-in. Connect directly to your personal Vikunja server and enjoy a tactile, desktop-grade task management experience in your pocket.

==================================
✨ KEY FEATURES
==================================

🔒 100% PRIVATE & SELF-HOSTED
• Direct connection to your own Vikunja instance (API token or credentials).
• Zero telemetry, zero analytics, zero ad trackers, and zero external heartbeats.
• Hardware-backed credential encryption (Android Keystore).
• Optional Biometric Lock (Fingerprint / Face ID).

⚡ OFFLINE-FIRST & ZERO LATENCY
• Create, edit, reorder, and complete tasks with instantaneous 0ms local response.
• Robust background sync queue automatically pushes edits and resolves conflicts when connectivity returns.
• Active-aware background sync that saves battery and bandwidth.

🎯 RAPID NATURAL LANGUAGE QUICK-ADD
• Type tasks effortlessly with smart shortcut parsing:
  - Add labels with `#tag`
  - Set priority with `!urgent`, `!high`, `!medium`, or `!low`
  - Assign teammates with `@username`
  - Schedule deadlines with `@today`, `@tomorrow`, or natural dates
• 1-tap priority cycling and autocomplete suggestion chips.

📋 COMPLETE PROJECT & LIST MANAGEMENT
• Multi-project drawer with live task count badges.
• Consolidated "All Tasks" and "My Open Tasks" smart views.
• Color-coded lists and custom project organization.
• Instant 1-tap task relocation between lists.

🔍 DETAILED TASK CONTROLS
• Subtasks and nested checklist items.
• Due dates, start dates, end dates, and reminder intervals.
• Percent progress tracking (0% to 100%).
• Priority indicators with clean color highlights.
• Markdown notes and task descriptions.

🎨 MODERN, TACTILE UX
• Fluid gesture controls: swipe right to complete, swipe left to move or delete.
• Haptic feedback engineered for satisfying tactile confirmation.
• True dark theme and AMOLED black optimization.

==================================
⚠️ PREREQUISITES
==================================
Guanaco is a client application and requires an existing Vikunja server instance (self-hosted via Docker, Kubernetes, or hosted cloud). Vikunja is an open-source project created by Kolaente.

Take back ownership of your tasks and projects with Guanaco.
```
